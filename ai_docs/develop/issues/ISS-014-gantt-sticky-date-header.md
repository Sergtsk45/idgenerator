# Issue: Sticky-строка дат при вертикальной прокрутке Gantt

**ID:** ISS-014  
**Discovered:** 2026-08-01  
**Reported by:** Sergey (product feedback)  
**Severity:** Low (UX)  
**Type:** Feature / Tech debt  
**Status:** Done (2026-08-01)  

## Description

На экране Schedule (диаграмма Ганта) при прокрутке графика **вниз** строка с датами (временная шкала сверху) уезжает вместе с контентом и перестаёт быть видимой. Нужно, чтобы даты оставались закреплёнными сверху тонкой sticky-строкой, пока пользователь просматривает нижние задачи.

## Current Behavior

Вертикальный scroll контейнера Gantt уводит заголовок шкалы дат из viewport — ориентироваться по датам при длинном списке задач неудобно.

## Expected Behavior

- При вертикальной прокрутке области задач шкала дат остаётся видимой сверху.
- Закреплённая строка — **тонкая** (компактная высота), без лишнего chrome.
- Горизонтальная прокрутка таймлайна по-прежнему синхронизирует даты и полосы (sticky только по вертикали).
- Поведение не ломает текущую tablet/mobile адаптацию (`04-schedule-acts.md`).

## Why Not Fixed Now

- Не блокирует основной сценарий планирования и генерации актов.
- Требует аккуратной вёрстки sticky + sync горизонтального scroll в `Schedule.tsx` (левая панель / таймлайн).
- Можно взять отдельно как UX-полировку после стабилизации Gantt-align/order.

## Proposed Solution

1. Вынести/закрепить header шкалы дат (`position: sticky; top: 0`) внутри вертикально скроллируемого контейнера таймлайна.
2. Сохранить z-index и фон, чтобы полосы задач не просвечивали под датами.
3. Проверить sync с левой колонкой задач (имена/коды) — при sticky дат левый header (если есть) тоже должен оставаться согласованным.
4. Smoke на desktop + tablet landscape с длинным списком задач и горизонтальным scroll.
