# План: Перестройка левой строки Gantt («Наименование работ»)

**Создан:** 2026-08-01  
**Статус:** Выполнено 2026-08-01  
**Объём:** UI-only, один файл (`client/src/pages/Schedule.tsx`)  
**Приоритет:** Средний (UX полировка)

---

## Цель

Упростить левую ячейку строки задачи на `/schedule`: убрать блок даты, поставить код позиции слева, а объём перенести в первую строку между бейджем метаданных и кнопками действий.

---

## Текущее состояние (as-is)

```
[дд]  [ акт N · X ч · 0 чел ]              [▾ ← → ✂ ⋮]
[MMM] [ Наименование работ…             ] [1/3]
[EEE] [ КОД ]  [ объём ед.изм. ]
```

- Блок даты (`dd` / `MMM` / `EEE`) — слева, только `md+`
- Строка 1: бейдж метаданных + кнопки
- Строка 2: наименование (+ бейдж split)
- Строка 3: код + объём

---

## Целевое состояние (to-be)

```
[КОД]  [ акт N · X ч · 0 чел ]  [ объём ед. ]  [▾ ← → ✂ ⋮]
       [ Наименование работ…                 ] [1/3]
```

### Горизонтально

| Зона | Содержимое |
|------|------------|
| Слева | Код позиции (`codeLabel`: `lineNo` / `code` / `ID:…`), моноширинный; **всегда виден** (mobile + md+) |
| Центр | Две строки контента (см. ниже) |

### Вертикально (центр)

**Строка 1 — метаданные + объём + действия**
- **Слева:** бейдж `акт N · X ч · Y чел` (логика без изменений: акт из задачи, ТЗ из сметы, бригада пока `0`)
- **Посередине:** объём задачи + единица (`quantity` + `task.unit || unit`); при `quantity == null` — **«—»**
- **Справа:** кнопки без изменений (раскрытие aux, ←/→, split, меню)

**Строка 2 — наименование**
- Название (`title`) с `line-clamp-1`
- Бейдж split `позиция/всего` (если есть)

**Строка 3** — удаляется (код и объём переехали вверх).

---

## Принятые решения (подтверждено 2026-08-01)

1. **Дата полностью убирается** из левой колонки (дата остаётся на таймлайне справа и в диалоге редактирования).
2. **Код** занимает место даты: узкая колонка слева (`shrink-0`), **всегда виден** — и на mobile, и на md+ (не `hidden md:block`).
3. **Объём** в строке 1 — компактный текст (`font-semibold text-primary`), с единицей измерения; при `quantity == null` показывать **«—»**.
4. **`rowHeight`**: снизить с `88` до **`72`**; выравнивание баров Ганта (`top` по центру строки) через существующую формулу.
5. **Aux-строки** не трогаем.
6. Backend / API / схема — без изменений.
