### 1.3 Ключевые отличия от текущего стиля

| Аспект | Текущий (shadcn/glass) | Odoo-стиль (целевой) |
|--------|------------------------|----------------------|
| Тени | Glassmorphism, blur | Плоские, едва заметные |
| Фон карточки | Полупрозрачный (.glass-card) | Сплошной белый, тонкий border |
| Бордеры | Скрытые или мягкие | Явные 1px solid --gray-200 |
| Скругления | 6-9px | 8-12px (чуть крупнее) |
| Интерактив | Framer Motion везде | CSS transitions, анимации только для feedback |
| Иконки | Lucide с разным strokeWidth | Lucide strokeWidth=1.5 единообразно |
| Кнопки | shadcn variants | Odoo-стиль: filled primary + ghost secondary |

## 2. Типографика

### 2.1 Шрифтовая шкала

**Odoo использует**: системные шрифты, простая иерархия.
**Наш компромисс**: оставляем Inter (хорошо читается на мобильных), убираем Outfit.

```
Роль             Шрифт       Размер   Вес    Высота строки
─────────────────────────────────────────────────────────────
Page Title       Inter       20px     600    28px         (1 на страницу)
Section Title    Inter       16px     600    24px         (заголовок секции)
Card Title       Inter       14px     600    20px         (заголовок карточки)
Body             Inter       14px     400    20px         (основной текст)
Body Small       Inter       13px     400    18px         (вторичный текст)
Caption          Inter       12px     400    16px         (подписи, hint)
Overline         Inter       11px     600    14px         (uppercase лейблы секций)
Mono (данные)    JetBrains   13px     400    18px         (числа в таблицах, коды)
```

### 2.2 Правила типографики

- **Overline**: `text-transform: uppercase; letter-spacing: 0.05em; color: var(--gray-500)`
- **Числа в таблицах**: `font-variant-numeric: tabular-nums` (моноширинные цифры)
- **Длинный текст**: `line-clamp: 2` для карточек, полный текст по нажатию
- **Placeholder**: `color: var(--gray-500); font-style: normal` (НЕ italic)

  font-size: 12px                   кнопки: 32×32px
  color: --gray-500                 active: bg --primary-500, color white

Реализация Infinite Scroll (React):

  const { data, fetchNextPage, hasNextPage, isFetchingNextPage } =
    useInfiniteQuery({
      queryKey: ['acts'],
      queryFn: ({ pageParam = 0 }) => fetchActs({ offset: pageParam, limit: 10 }),
      getNextPageParam: (lastPage, allPages) =>
        lastPage.length === 10 ? allPages.flat().length : undefined,
    });

  // IntersectionObserver на последнем элементе
  const observerRef = useRef<IntersectionObserver>();
  const lastElementRef = useCallback((node: HTMLDivElement) => {
    if (isFetchingNextPage) return;
    if (observerRef.current) observerRef.current.disconnect();
    observerRef.current = new IntersectionObserver(entries => {
      if (entries[0].isIntersecting && hasNextPage) fetchNextPage();
    }, { rootMargin: '200px' });
    if (node) observerRef.current.observe(node);
  }, [isFetchingNextPage, hasNextPage, fetchNextPage]);
