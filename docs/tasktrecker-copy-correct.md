# Task Tracker: штамп «Копия верна» на копиях документов качества

> **Фича**: `copy-certify-stamp`
> **Дата фиксации требований**: 2026-07-31
> **Статус**: Завершена локально (2026-08-01)
> **Зависимость**: формирование пакета приложений к акту в виде отдельного PDF с копиями документов качества — реализовано

---

## Цель

При сборке PDF-пакета приложений к акту накладывать на каждую страницу каждой копии документа качества визуальный штамп «Копия верна» в стиле ручной печати, с должностью и ФИО ответственного сотрудника объекта.

Штамп — **только визуальная пометка**, без электронной подписи (ЭП).

---

## Источник данных

| Параметр | Решение |
|----------|---------|
| Таблица | `object_responsible_persons` (переиспользовать) |
| Роль | `copy_certifier` (новая) |
| Поля | `person_name` (ФИО), `position` (должность) |
| Область | уровень объекта — одни данные для всех актов объекта |
| UI | исходные данные объекта, блок ответственных |
| Дата в штампе | не нужна |
| Факсимиле подписи | не в v1 — только линия подписи |

Если должность и/или ФИО не заполнены: ставить штамп с **пустыми подчёркиваниями** (вариант B). Сборку пакета не блокировать.

---

## Внешний вид штампа

```
┌─────────────────────────────┐
│        Копия верна          │
│   <должность> / <ФИО>       │
│   _______________           │  ← линия подписи
└─────────────────────────────┘
```

При пустых полях:
```
┌─────────────────────────────┐
│        Копия верна          │
│   ___________ / ___________ │
│   _______________           │
└─────────────────────────────┘
```

| Параметр | Значение |
|----------|----------|
| Размер | 70 × 35 мм |
| Макет | «Копия верна» + «&lt;должность&gt; / &lt;ФИО&gt;» + линия подписи |
| Рамка | как у классической печати |
| Позиция | правый нижний угол страницы, отступ 10 мм от правого и нижнего края |
| Угол | фиксированный −12°; одинаковый и воспроизводимый при повторном экспорте |
| Цвет | классический сине-фиолетовый чернил печати |
| Непрозрачность | ~60–80% |
| Зернистость | best-effort: лёгкая текстура чернил без требования к пиксельному совпадению с эталоном |
| Слой | overlay поверх содержимого страницы |

### Переполнение и малые страницы (v1)

- Должность и ФИО рисуются в одной строке, разделённой `/`.
- Для длинной строки размер шрифта уменьшается до 7 pt; если строка всё ещё не помещается, она обрезается по доступной ширине с многоточием.
- Заголовок и линия подписи не обрезаются.
- На странице, где штамп 70 × 35 мм с учётом поворота и отступов не помещается, весь штамп пропорционально уменьшается до доступной области; минимальный отступ от краёв после уменьшения — 5 мм.

---

## Правила наложения

1. Штамп на **каждую страницу** многостраничного документа.
2. В одном многостраничном PDF — **один штамп на страницу** (не один на весь документ).
3. Штампуются страницы **всех вложений**, включённых в пакет через `act_document_attachments`, независимо от типа документа.
4. Титульная страница пакета **не штампуется**.
5. В v1 поддерживаются только PDF-вложения; JPEG/PNG не входят в скоуп.
6. Исходные файлы документов качества в хранилище **не изменяются**; штамп только на копиях в пакете.
