# Task Tracker: штамп «Копия верна» на копиях документов качества

> **Фича**: `copy-certify-stamp`
> **Дата фиксации требований**: 2026-07-31
> **Статус**: Не начата (ожидает реализации PDF-пакета приложений к акту)
> **Зависимость**: формирование пакета приложений к акту в виде отдельного PDF с копиями документов качества

---

## Цель

При сборке PDF-пакета приложений к акту накладывать на каждую страницу каждой копии документа качества визуальный штамп «Копия верна» в стиле ручной печати, с должностью и ФИО ответственного сотрудника объекта.

Штамп — **только визуальная пометка**, без электронной подписи (ЭП).

---

## Источник данных

| Параметр | Решение |
|----------|---------|
| Таблица | `object_responsible_persons` (переиспользовать) |
| Роль | `copy_certifier` (новая) |
| Поля | `person_name` (ФИО), `position` (должность) |
| Область | уровень объекта — одни данные для всех актов объекта |
| UI | исходные данные объекта, блок ответственных |
| Дата в штампе | не нужна |
| Факсимиле подписи | не в v1 — только линия подписи |

Если должность и/или ФИО не заполнены: ставить штамп с **пустыми подчёркиваниями** (вариант B). Сборку пакета не блокировать.

---

## Внешний вид штампа

```
┌─────────────────────────────┐
│        Копия верна          │
│   <должность> / <ФИО>       │
│   _______________           │  ← линия подписи
└─────────────────────────────┘
```

При пустых полях:
```
┌─────────────────────────────┐
│        Копия верна          │
│   ___________ / ___________ │
│   _______________           │
└─────────────────────────────┘
```

| Параметр | Значение |
|----------|----------|
| Макет | две строки: «Копия верна» + «&lt;должность&gt; / &lt;ФИО&gt;» + линия подписи |
| Рамка | как у классической печати |
| Позиция | правый нижний угол страницы |
| Угол | базовый ~−15°, лёгкая рандомизация **±2–3° на каждую страницу** |
| Цвет | классический сине-фиолетовый чернил печати |
| Непрозрачность | ~60–80% |
| Зернистость | лёгкая текстура чернил (имитация ручной печати) |
| Слой | overlay поверх содержимого страницы |

---

## Правила наложения

1. Штамп на **каждую страницу** многостраничного документа.
2. В одном многостраничном PDF — **один штамп на страницу** (не один на весь документ).
3. Исходник-изображение (JPEG/PNG) при включении в пакет — **тоже штампуется**.
4. Исходные файлы документов качества в хранилище **не изменяются**; штамп только на копиях в пакете.

---

## Acceptance criteria

- [ ] Роль `copy_certifier` поддерживается в `object_responsible_persons`; UI исходных данных позволяет задать должность и ФИО.
- [ ] При сборке пакета приложений на каждой странице каждой копии виден штамп по шаблону выше.
- [ ] Штамп в правом нижнем углу, под углом с рандомизацией ±2–3°, сине-фиолетовый, полупрозрачный (~60–80%), с зернистостью и рамкой.
- [ ] JPEG/PNG-сканы в пакете тоже получают штамп.
- [ ] При пустых должности/ФИО пакет собирается, штамп рисуется с пустыми подчёркиваниями.
- [ ] Файлы документов качества в хранилище после экспорта не изменены.
- [ ] Данные штампа берутся из `copy_certifier` текущего объекта.
- [ ] ЭП / факсимиле подписи в v1 отсутствуют.

---

## Вне скоупа (v1)

- Электронная подпись (ЭП)
- Дата в штампе
- Переопределение ответственного на уровне акта / экспорта
- Факсимиле подписи (картинка)
- Изменение исходных файлов документов качества
