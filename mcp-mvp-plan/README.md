# MCP-IDgenerator: пакет планирования первого MVP

**Проект:** `Sergtsk45/idgenerator`  
**Дата:** 2026-08-02  
**Цель:** реализовать сквозной MVP, в котором AI-агент принимает смету, поэтапно запрашивает недостающие сведения, формирует график, реестр материалов и документов качества, затем готовит акты и журнал работ через MCP-IDgenerator.

## Состав пакета

| Файл | Назначение |
|---|---|
| `00-mvp-scenario.md` | Полный пользовательский и системный сценарий MVP |
| `01-architecture-and-boundaries.md` | Целевая архитектура, границы агента и MCP |
| `02-implementation-roadmap.md` | Этапы и последовательность реализации |
| `03-epic-task-list.md` | Укрупнённый список задач и зависимости |
| `04-agent-prompting-standard.md` | Единый стандарт заданий для кодового агента |
| `tasks/TASK-001-*.md` … `TASK-012-*.md` | Отдельное задание агенту на каждую крупную задачу |

## Рекомендуемый порядок работы

1. Прочитать `00-mvp-scenario.md` и утвердить границы MVP.
2. Проверить архитектурные решения в `01-architecture-and-boundaries.md`.
3. Выполнять задачи строго в порядке зависимостей из `03-epic-task-list.md`.
4. На каждую задачу создавать отдельную ветку и отдельный pull request.
5. Перед началом задачи агент обязан изучить локальные `AGENTS.md`, `.cursor/rules`, связанные ADR и существующие тесты.
6. После каждой задачи запускать:
   - `npm run check`
   - `npm test`
   - `npm run build`
7. Не объединять несколько TASK-файлов в один большой PR без отдельного решения руководителя проекта.

## Основной принцип

AI-агент ведёт диалог, выбирает следующий шаг и объясняет результат. MCP-IDgenerator хранит состояние, проверяет права, выполняет детерминированные операции и формирует документы.
